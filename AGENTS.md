## Non-negotiable rules

1. **Never log a raw email or Spotify token.** Hash emails via `server/services/utl/hashUserId.js`.
2. **Never `console.*` in `server/`** — use the Pino logger at `server/services/logger.js`.
3. **No `npm install`, `git push`, `azd up`, or destructive scripts without explicit user OK.**
4. **Default to no comments.** Add one only when the *why* is non-obvious; one short line max.
5. **Match existing patterns** (route shape, Redux slice shape, error handling). Don't introduce a new pattern unless asked.

## Things this codebase intentionally does

- Sequelize `sync({ alter: true })` on every boot — no migration tool.
- Intro audio cache key includes `personaVersion` + `promptVersion`; edits fork the cache naturally.
- `UserIntroPlayed` suppresses the intro on the second listen — by design.
- Static images live on disk; only generated audio goes to blob.
- No CDN in front of blob; browser cache is enough at our scale.

## Dev URL

`http://127.0.0.1:3000` — not `localhost`. Spotify OAuth fails on the wrong host.
